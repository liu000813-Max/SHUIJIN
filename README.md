# 水晶工作室 · Crystal Atelier

一个从出生日期开始的水晶手串互动网页：认识你的幸运水晶，进入材料桌自由串珠，并保存一张专属幸运卡。

## 本地运行

```bash
npm install
npm run dev
```

## V1 功能

- 出生日期推算西方星座（时间和地点为可选输入）
- 三颗个性化水晶推荐与寓意展示
- 24 个圆形串珠槽位，支持点击添加、拖拽替换、点击移除、重置
- 水晶 / 隔珠 / 吊坠材料分类
- AI DESIGN 演示模式，自动生成一套搭配
- 完成手串后生成可下载的幸运卡 PNG
- 使用 localStorage 保存出生信息和当前设计

水晶寓意属于文化与生活方式体验，不替代医学、科学或命理诊断。
